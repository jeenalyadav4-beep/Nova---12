# Nova---12 Operating system

Welcome to the future of desktop. **Nova 12** is an independent, high performance operating system designed to bring back the beautiful styling of classic glass desktop interface

## Core Features
* **Aero Glass interface:**smooth, transparent window borders inspired by classic layouts
* **Lighting Fast:**Stripped of modern tracking and bloatware so your PC runs at full speed
* **Built on a Rock solid Core:** Powered by an ultra-stable base that bypasses many OS

## Release date
* **Alpha test:** Interface design and icon mapping.
* **beta Test:** Public ISO release for USB boot testing.
* **Final Launch:** Full global distibution on SourceForge and Github
